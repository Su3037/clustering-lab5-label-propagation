# 自己学懂标签传播

这份讲义对应 Clustering Lab05。先用 10 分钟建立概念，再拿一张小图验证。所有“2轮、cutsize3”的说法都限于下文的图和规则。

## 先分清三个词

- 节点：图中的对象。本例的节点名始终是 A、B、C、D、E。
- 标签：节点当前携带的群体记号，会更新。节点 A 最后携带标签 B，并不代表节点改名了。
- 边权：本次模型中连接的强弱。它不是人数，也没有自动对应现实的因果强度。

## 一次更新怎样计算

对节点 v，把邻居按当前标签分组，同组边权加起来，取总和最大的标签。

`score_v(L) = Σ w(v,u) · [label(u) = L]`

平票必须有明确规则。课堂例子取字典序最小的候选标签。没有邻居就不改。

## 指定小图和默认规则

边为 AB=5、AC=1、BC=4、CD=2、DE=5、CE=1。初始各自为标签。按 A B C D E 异步访问：每次更新立即写回。边是无向的，每条边在割边统计中只算一次。

| 第1轮访问 | 当时看到的票数 | 新标签 | 改变 |
| --- | --- | --- | --- |
| A | B:5，C:1 | B | 是 |
| B | B:5，C:4 | B | 否 |
| C | B:1+4=5，D:2，E:1 | B | 是 |
| D | B:2，E:5 | E | 是 |
| E | B:1，E:5 | E | 否 |

第1轮结束为 B B B E E，3个节点改变。第2轮重新检查5个节点，全部不变，确认稳定，所以轮数为2。分组是 {A,B,C} 与 {D,E}。

跨组的是 CD 和 CE，共两条边。加权 cutsize = 2+1 = 3。原图总边权是18，分组规模3:2。这里把规模列为观察指标，没有施加均衡约束。

## 同步与异步

同步：本轮全部节点只读本轮开始时的旧标签，先计算待写回值，轮末统一提交。

异步：按访问顺序逐个写回，后面的节点会读到前面刚产生的新值。

只看一条 A—B 边。同步 A/B 会先变 B/A，再变 A/B，产生2周期振荡。异步 A先更新后是B/B，下一轮零变化。网页遇到完整状态重复会报告 cycle 并停止，避免把重复当稳定或永久播放。

## 顺序和平票

同一小图倒序 E D C B A，独立运行得到 A A A D D，含确认轮共3轮。分组还是三点和两点，但标签名与过程不同。其他图、权重或规则也可能改变分组，不能据此认为顺序只影响名字。

最小标签、最大标签、保留当前优先都是可定义的平票方式。本项目默认最小标签以对应课程。随机方式需要记录随机种子；实验未把未实现的随机开关放进界面。

## 怎样停止

1. stable：完整一轮没有标签改变。
2. cycle：完整的标签状态再次出现，说明当前确定性规则与顺序下进入循环。
3. limit：达到预设安全上限，尚未确认稳定或循环。

本项目的判断基于全轮边界。默认最大50轮。不能把 limit 写成已经收敛。

## 为什么 cutsize 小并不等于好

把所有节点放进同一组时 cutsize=0，但未必满足任务。这种基本 LP 不是受约束的最小割求解器，不保证群体数、规模均衡、时序可行或全局最优。

每一轮通过邻接表累计票数，通常按边遍历计算；整体耗时还取决于轮数、平票候选处理和输入。不要把论文的近线性经验标题理解为任意图都固定两轮。

## 与 VLSI 的关系

用单元与连线建立图模型后，LP可以提供粗化或初始社区的线索。真实网表也可能采用超图模型。实际物理划分还需考虑面积、时序、拥塞等约束，本实验不替代商业EDA流程。

## 你能讲出来，就算真正理解了

先不看答案，回答：为什么 C 的 B 票数是5？为什么第1轮结束仍未报告稳定？cutsize3和两条切边有什么区别？同步双节点为何振荡？标签名字不同是否等于分组不同？

推荐演示顺序：网页第一个图单步3次，读出票数；完成两轮；切换双节点和同步模式；运行并观察振荡；回到教师图，改变 CD 权重后重新比较。
