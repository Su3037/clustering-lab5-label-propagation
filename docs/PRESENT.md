# 课堂展示提纲

这是建议的展示组织，不是老师规定的统一时长。

## 开场

打开网页顶部，播放3分49秒主片。如果课堂时间有限，可切换1分27秒的五节点推演。无配音版本需要观众留出阅读字幕的时间，教室音响不方便时静音仍能理解。

## 讲清一个小例子

使用课件第4页说明图，第5–7页说明第一轮。特别解释C：A和B已经携带同一种标签B，因此AC与BC的权重1+4累计为5。不能把它讲成“最粗的那条边就是答案”。

第8页解释2轮包含确认轮，cutsize3是两条跨组边的权重和。第9页用双节点解释同步振荡。第10页区分标签名与分区。

## 让同学操作

1. 打开网页实验室，默认图单步访问A、B、C，让同学先预测C的选择。
2. 完成两轮，核对3:2分组和加权割边3。
3. 切换“两节点振荡”与同步模式，观察两轮后报告重复状态。
4. 回到教师图，改变桥边CD权重，比较更新规则和访问顺序。

## 说明自己的改进

保留了老师的图和基本规则，新增中文无配音知识动画、逐节点票数、同步振荡反例、可改参数实验、练习解析与跨语言验证。没有宣称提出新算法。

## 常见追问

- 为何初始化不只给两种颜色？基本LP起始每点独立标签，不预先指定群体数。
- 为什么不是看到两组就停？两组还可能继续变化，停止依据是整轮零变化。
- 所有人同色是不是最优？cutsize0不等于满足均衡、规模、时序等真实约束。
- 顺序只影响标签名字吗？此指定图正倒序分区相同，但其他图可能改变分区。
- 为什么谈生活？用熟悉的局部关系解释结构形成；不从图标签推断人的属性或社会因果。
