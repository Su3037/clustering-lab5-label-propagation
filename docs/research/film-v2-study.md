## 实际检查的参考片

实际取得并抽帧检查的是 [《信息论·惊奇之学》Bilibili 页面](https://www.bilibili.com/video/BV1GXav6iEWh/)，画面署名“电子智人”，对应[抖音作者发布页](https://www.douyin.com/video/7690337875291950345)。Bilibili公开接口在核对时返回约15.9万播放、14473赞；播放与点赞分开记录。

对约300秒视频按10秒间隔查看全片30个时间位置，检查开场、概念演示、现实载体转换和结尾；这属于实际抽帧研究，不称为带声实时看完。参考素材仅保存在忽略目录，用于分析，没有混入本项目成片。

从实际画面得到的观察：

1. 开头用观众能参与的具体情境引出疑问，片名稍后出现。
2. 同一知识可由不同载体展开：量化实验、地理场景、通信设备，画面不需要一直停在一个图上。
3. 放大局部计算时，坐标范围与对象一起变化；结论出现后留出阅读时间。
4. 叙事可回到开场的物件，让观众在理解后重新看它。

[《运气的形状》原发布页](https://www.douyin.com/video/7690344836800913785?previous_page=web_code_link)约60万赞、[博弈论参考片](https://www.douyin.com/video/7691569696105139471)约18万赞的公开页面已核对，但本次未取得可验证的原片画面，不写成亲自完整观看。其他人的[制作拆解](https://github.com/HeyChengC/vibe-knowledge-film/blob/main/references/analysis.md)只作为二手资料。

特别更正：此前记录的BV163aC6iEFj虽然标题写《运气的形状》，实际抽帧的画面标题是《平行时空》。不再依据该转载判断原作的画面、音乐或剪辑，避免把标题与实际内容混同。

## 原创改编的叙事与视觉

34个镜头约3分10秒；米白、鼠尾草绿、深青蓝三组纸面色调；人物为有手、脚、书本动作的二维形象。屏幕字幕保持稳定，运镜只作用于插画层。采用推近、拉远、俯视换景和短溶解，不让整屏文字跟着漂移。

一本书的递交 → 图书馆交流 → 桌面连接 → 标签 → 权重天平 → 汇票容器 → 课程小图约40秒 → 同步/异步信箱 → 24节点真实模拟 → 街区 → 桥边变化 → 电路单元 → 回到图书馆。

母题是书上的彩色标签：它可以成为图节点上的标签、信箱收到的标签、街区的群体色和电路单元的分组色。每到一个新载体，动作解释当前句子，而不是重复五节点图。最后带书跨过两个桌子的读者，表达“群体间仍可有连接”，不把社会比喻当成因果或人格结论。

课程指定五节点例子的票数、两轮、cutsize3仍来自真实引擎。新增24节点、86条边的虚构图也由同一引擎计算，得到3组、2轮、加权割边2；不是凭画面指定的答案。桥边改为10的反事实由引擎重新求解。
